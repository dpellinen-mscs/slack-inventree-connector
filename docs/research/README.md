## How to read these notes

- They are a snapshot. Versions, star counts and dates were correct on the
  research date and will age.
- Pages were read through a tool that summarizes, so quoted strings may
  not be verbatim. Follow the link before quoting a source.
- Each file ends with a list of unverified items. Nothing on those lists
  is a fact yet.
- A claim about InvenTree behavior becomes a fact for this project only
  when an integration test against a pinned version proves it. The design
  names the claims that safety depends on.
- Examples use invented names only.
